# Rogontra Pay

A responsive digital-wallet frontend prototype that demonstrates a clear payment experience across a landing page, dashboard, transfer review flow, transaction history, and support pages.

**Live demo:** [golden2524.github.io/RogontraPay](https://golden2524.github.io/RogontraPay/)

> This is a frontend portfolio project. It does not create real accounts, process payments, or store personal information.

## Preview

Rogontra Pay is designed around three simple product ideas:

- Make balances and recent activity easy to scan.
- Let users review transfer details before a future confirmation step.
- Be clear about what the prototype does and does not do.

## Features

- Responsive landing page with product, trust, help, and legal information.
- Mobile navigation drawer with keyboard support and Escape-to-close behaviour.
- Dashboard with a balance visibility toggle, quick actions, chart, and recent activity.
- Transfer flow with browser validation and a client-side review screen.
- Filterable transaction history.
- Login, sign-up, and contact form interactions presented as frontend demonstrations.
- Accessible basics including semantic landmarks, labelled form controls, visible keyboard focus, and live status messages.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter)

## Run locally

This is a static website, so no installation is required.

1. Clone the repository.
2. Open `index.html` in a browser, or serve the folder with any static-server extension.
